**Why this matters.** You are asked to let a program read your coding sessions, which hold your prompts and your code. These pages let you check, before you install it, exactly what it reads and uploads, and what each claim was tested against.

These pages document the open-source [AgentsOfMine collector](https://github.com/AgentsOfMine/collector). They are written and maintained by the AgentsOfMine project. Each claim is marked as tested (run on a real install), read from source, or assumed from the vendor's documentation.

## Who needs this

**Possible scenario.** You are asked to approve a tool that reads coding sessions, and you have an afternoon. You do not want a vendor's summary. You want to know which statements were checked by running something, which were read from source, and which are only the vendor's word. Every page here marks which is which, so you can decide where to look yourself.

| Role | What changes for them |
|---|---|
| CTO or engineering lead | Can see which claims rest on a test and which on documentation, and ask for the rest before approving. |
| Architect | Gets the version and the commit each claim was checked against, so a later change can be noticed. |
| Junior software engineer | Learns what "checked" means here and can reproduce a claim with the command given. |

Table: who gains what, **my reasoning, not measured.** I did not measure time saved for any role.

## How a page is made

Each page says at the top what it was checked against and on which day. A claim comes from one of three places: the collector's source (with a command you can run), a file on a real install, or the vendor's own documentation. Where a claim could not be checked, the page says so. Some pages are drafted with AI assistance; every command and claim is checked and edited by a person before it is published.

If something here is wrong, [open an issue](https://github.com/AgentsOfMine/collector/issues). We fix it and note the change.

## What this site records

This site sets no cookies, runs no scripts of its own and loads nothing from other websites: fonts and images come from the site itself. It is hosted on GitHub Pages, so **GitHub** serves every request. We do not receive logs or visit counts from GitHub, and we do not add analytics.

GitHub's privacy statement says it logs, for its services, the IP address, the pages viewed and the referring site. I have not verified whether and how that applies to a Pages site, so treat GitHub as able to see that you visited. Read [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) for what it says.

The product website, [agentsofmine.io](https://agentsofmine.io), and the [blog](https://blog.agentsofmine.io) each have their own privacy page.
